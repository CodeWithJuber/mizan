# 04 — The Generative Algebra (Phase 1)

Classical Arabic morphology is famously generative: a small set of **roots** (usually three
radicals) is poured into a set of **patterns** (awzān) to produce words, where the root carries
the semantic field and the pattern carries the grammatical/derivational role. This phase makes
that system explicit and measures it.

---

## 4.1 The model

For each lemma, align its radicals onto the canonical template slots **ف-ع-ل** (fāʾ-ʿayn-lām;
a fourth radical takes a second lām). What remains after substituting the slots back to ف/ع/ل
**is** the pattern (wazn). Examples that validate the extractor `[Established]`:

| Word | Extracted wazn |
|---|---|
| kātib (writer) | fāʿil |
| maktūb (written) | mafʿūl |
| raḥīm (merciful) | faʿīl |
| istighfār (seeking forgiveness) | istifʿāl |
| miftāḥ (key) | mifʿāl |

Shadda is handled naturally (it yields Form II, faʿʿala). **Weak roots** — where a radical
(و / ي / ء) mutates or drops — are flagged `irregular` rather than forced into a wrong template.

## 4.2 What the grid looks like `[Established]`

| Quantity | Value |
|---|---|
| Lemmas with a root | 4 629 |
| Lemmas that align cleanly to a wazn | 3 684 (**80%**) |
| Lemmas that are weak/irregular (flagged, not faked) | 945 (**20%**) |
| Distinct roots (R) | 1 456 |
| Distinct patterns (P) | 565 |
| Realised lemmas (L) | 3 684 |
| Full R × P grid | 822 640 cells |
| Grid fill | **0.45%** |

The grid is **extremely sparse** — and that is exactly right. Of all conceivable
root×pattern combinations, only a tiny fraction are actually used; the language is generative
but selective.

**Concentration** `[Established]`: the long tail of 565 patterns is misleading on its own,
because the head dominates. The **top-20 patterns account for 47%** of all derived lemmas. The
most frequent awzān are the textbook ones:

```
faʿl 281 · fāʿil 180 · faʿal 164 · faʿīl 155 · faʿala 114 · fāʿila 87 · mafʿūl 76
· ʾafʿal 66 · faʿāl 66 · fiʿāl 63 · fiʿl 61 · faʿla 58 · faʿʿala 52 · fuʿl 51 · ʾafʿala 50
```

**Most productive roots** (most distinct patterns) `[Established]`: k-b-r, ṣ-d-q, kh-l-f (18
patterns each); s-l-m (15); ʿ-l-m (14).

## 4.3 Coverage at the token level `[Established]`

Of all 77 429 running tokens, how many does root×pattern actually generate?

| Bucket | Tokens | Share |
|---|---|---|
| Generated by root × pattern | 36 252 | 46.8% |
| Has a root but opaque/weak (not cleanly generated) | 14 016 | 18.1% |
| Pronouns / proper nouns (no root) | 13 972 | 18.0% |
| Function words / particles (no root) | 13 189 | 17.0% |

So roughly **65% of running text is root-based**, and the remaining ~17% is closed-class
function vocabulary that lives **outside** the algebra by nature. `[Inference]` A generative
root-grammar is the right model for the content layer of the text, but it is not a theory of
*everything* in the text — particles and pronouns are a separate, finite system.

## 4.4 Forward generation — "make the word from the root"

The inverse direction was tested too: given (wazn, root), instantiate the surface word by
substituting radicals into the ف/ع/ل slots.

**Strong roots work** `[Established]`:

| Root | Attested forms recovered |
|---|---|
| ṣ-d-q | 6/8 (ṣadq, ṣādiq, ṣadaq, ṣadīq, ṣadaqa, ṣādiqa) |
| s-l-m | 6/8 (salm, sālim, salam, salīm, salama, salām) |
| ḥ-m-d | ḥamada, maḥmūd … |

**Weak roots need special rules** `[Established]`: q-w-l recovers only 3/8 because naïve
substitution yields *qāwil* where the language requires *qāʾil*. Completing this (the
hollow / defective / hamzated / assimilated root rules) is the **weak-root engine** on the
roadmap (`07_synthesis_mizan_roadmap.md`).

## 4.5 The 28-letter feature space

To make "letters" first-class objects (and to set up the sound-meaning tests in
`05_sound_meaning_nulls.md`), each of the 28 Arabic letters is encoded as a 15-dimensional
feature vector over articulation features:

- **Makhraj (place):** throat / tongue / lips / jawf (one-hot of 4 regions).
- **Ṣifāt (manner):** voiced, emphatic (the 7 letters خصضغطقظ), qalqalah (the 5 قطبجد),
  sibilant, nasal, lateral, trill, stop, fricative, approximant, plus a dots feature.

A root then becomes either a 28-dimensional indicator (which letters it contains) or the mean
of its letters' feature vectors. See `letter_math.png`.

`[Inference]` Every one of these phonological features is a **binary opposition** (voiced vs
voiceless, emphatic vs plain, …) — which is exactly Jakobson's theory of distinctive features.
That is the honest, established structural sense in which Arabic phonology is "built from
pairs." Whether those pairs carry *meaning* is the separate question answered (negatively) in
the next file.
